# 三个指针为何能低于 −1/8

想象三支指针，每支从零附近出发，最后可能停在零点左边或右边。每轮把三个有正负号的读数相乘，再对所有轮次求平均。Abbott、Silva、Wechs、Brunner 和 Branciard 问，这个平均值在适当归一化后，是否总大于等于 $-1/8$？对允许任意秩的投影测量，**第三支指针就能打破这个下界**。Haobo Ma 和 Wenlin Zhang 给出一个三维例子，得到 $-1/6$，并求出任意长度的最小值。长度为三时，真正的最小值是 $-81/448$。所有有限长度的最小值逐步接近 $-1/3$。

## 一次只保留一个方向会怎样？

在纸上画一条过原点的直线。把一个箭头垂直投影到直线上，就是保留沿直线的分量。矩阵 $P$ 表示这个操作。友好的两个例子是 $P(x,y)=(x,0)$ 和 $Q(x,y)=((x+y)/2,(x+y)/2)$，分别保留横轴方向和对角线方向。对 $(0,1)$ 先做 $Q$ 再做 $P$ 得到 $(1/2,0)$，先做 $P$ 再做 $Q$ 则得到零。两个操作都只保留分量，结果却取决于次序。

在更高维空间里，投影可以保留一个方向，也可以保留整个平面。留下的空间的维数叫作**秩**。投影在留下的方向上作用为 $1$，在垂直的方向上作用为 $0$。写成矩阵，正交投影满足 $P=P^*=P^2$，其中 $P^*$ 是共轭转置。

## 从读数到矩阵

理想实验为每次测量配一支独立的指针，初始位置以零为中心。如果量子态完全落在第 $j$ 个投影保留的空间里，该指针的初始分布向右移 $h_j$。如果量子态完全落在垂直空间里，指针没有平移。一般状态会同时含有这两种分量。每次测量后保留整轮数据，不依末态筛选实验轮次。以 $x_j$ 表示读数，测量量是 $\mathbb E[x_1\cdots x_n]/(h_1\cdots h_n)$。固定测量的个数、初态和投影，同时减小耦合，得到弱极限 $\mu_n$。高斯模型如何得到这个极限，见[有限强度一章](extensions.md)。

矩阵计算从最后一个投影开始。设 $\mathcal J_P(X)=(PX+XP)/2$，称为 **Jordan 乘积**。用 $\mathcal J_{P_j}$ 将前一个测量纳入，始终取两种矩阵乘法次序的平均。

$$
X_n=P_n,\qquad X_j=\mathcal J_{P_j}(X_{j+1}),\qquad
\mu_n=\operatorname{Tr}(\rho X_1).
$$

每个 $X_j$ 都是厄米矩阵，即 $X_j^*=X_j$，其特征值为实数。若初态是单位向量 $\psi$，上式就是实数 $\langle\psi,X_1\psi\rangle$。更一般的密度矩阵 $\rho$ 是半正定且迹为 $1$ 的矩阵。它把若干纯态的期望按非负权重平均，权重之和为 $1$。单个投影的期望因此介于 $0$ 和 $1$ 之间。嵌套平均里的负数从哪里来？[三维反例](witness.md)把它变成一次可以手算的点积。
